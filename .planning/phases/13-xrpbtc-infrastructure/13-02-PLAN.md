1. **sync_service.py** -- In the fill processing flow (where lots are created from buy fills), add BTC/EUR rate fetching for non-EUR-quoted pairs:
   - After creating the lot via `create_lot_from_buy_fill()`, check if the lot's symbol is not EUR-quoted using `is_eur_quoted(symbol)` from symbol_registry
   - For non-EUR-quoted pairs (e.g., XRPBTC): fetch historical BTC/EUR rate at fill timestamp using the existing `BinancePublicClient.get_klines("BTCEUR", "1m", limit=1, start_time=ts_ms)` pattern (already used in `_get_per_fill_fee_conversion_rates()`)
   - Compute: `btceur_rate = Decimal(str(klines[0][4]))` (close price)
   - Update the lot_db: `lot_db.cost_eur = lot_db.cost_quote * btceur_rate` and `lot_db.quote_to_eur_rate = btceur_rate`
   - Use the same minute-caching pattern as `_get_per_fill_fee_conversion_rates()` to avoid redundant API calls for fills in the same minute
   - Fallback: if rate fetch fails, log warning and leave cost_eur as None (lot is created but EUR data missing -- can be backfilled later). Do NOT abort the sync.
   - Import `is_eur_quoted` from `app.symbol_registry`

2. **lot_service.py** -- In `create_lot_from_buy_fill()`, after creating `lot_db` from domain lot, handle the `quote_to_eur_rate` field:
   - Set `lot_db.quote_to_eur_rate = Decimal("1")` when lot is EUR-quoted (cost_eur == cost_quote)
   - Leave `lot_db.quote_to_eur_rate = None` when cost_eur is None (BTC-quoted, rate not yet available)
   - The sync_service will update both fields after fetching the historical rate

3. **scripts/backfill_cost_eur.py** -- Fix the float precision bug on line 197:
   - Change `{"cost_eur": float(cost_eur), "rate": float(btceur_rate), "lot_id": lot_id}` to `{"cost_eur": str(cost_eur), "rate": str(btceur_rate), "lot_id": lot_id}` -- SQLAlchemy text() params accept strings for Numeric columns
   - Verify this is the ONLY float() call in the script touching financial values
   - Also update the DB URL default from "pg" to reflect that this project uses SQLite (change `--db` default to "sqlite" and the SQLite URL to match `DB_URL` from .env or `"sqlite:///./cashmgnt.db"`)
