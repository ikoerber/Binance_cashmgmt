<objective>
Add EUR cost basis fields to the TradeLot domain model and compute EUR-normalized costs during lot creation.

Purpose: Every lot needs a deterministic EUR cost basis computed at fill time. EUR-quoted lots (BTCEUR, XRPEUR) trivially have cost_eur = cost_quote. Non-EUR-quoted lots (XRPBTC) need the historical BTC/EUR rate multiplied into cost_quote. This plan implements the pure domain logic (no I/O); the service layer integration follows in Plan 02.

Output: Extended TradeLot dataclass with cost_eur, quote_to_eur_rate, break_even_eur. Extended create_trade_lot_from_buy_fill() accepting quote_to_eur_rate parameter. Comprehensive test suite.
</objective>

    TradeLot dataclass extended with:
    - cost_eur: Optional[Decimal] = None (EUR-equivalent cost, None = needs backfill)
    - quote_to_eur_rate: Optional[Decimal] = None (conversion rate at fill time, None = needs backfill)
    - break_even_eur property: cost_eur / qty_base_initial (or None if cost_eur is None or qty is 0)

    create_trade_lot_from_buy_fill() extended with:
    - New optional parameter: quote_to_eur_rate: Decimal | None = None
    - Branch logic after existing cost_quote calculation:
      1. If get_quote_asset(symbol) == "EUR": set cost_eur = cost_quote, rate = Decimal("1")
      2. Elif quote_to_eur_rate is not None: set cost_eur = cost_quote * quote_to_eur_rate, rate = quote_to_eur_rate
      3. Else: set cost_eur = None, rate = None (needs backfill)
    - TradeLot constructor call includes cost_eur and quote_to_eur_rate

    Test cases (input -> expected output):
    - EUR-quoted buy fill (BTCEUR, price=90000, amount=0.01, no rate param) -> cost_eur = cost_quote (900.00), rate = 1.0, break_even_eur = 90000
    - EUR-quoted buy fill (XRPEUR, price=2.50, amount=100, no rate param) -> cost_eur = cost_quote (250.00), rate = 1.0, break_even_eur = 2.50
    - BTC-quoted buy fill (XRPBTC, price=0.00003, amount=100, rate=90000) -> cost_eur = 0.003 * 90000 = 270.00, rate = 90000, break_even_eur = 2.70
    - BTC-quoted buy fill (XRPBTC, price=0.00003, amount=100, no rate) -> cost_eur = None, rate = None, break_even_eur = None
    - EUR-quoted buy fill with BNB fee (BTCEUR, price=90000, amount=0.01, fee_asset=BNB) -> cost_eur still correct (includes fee in cost_quote), rate = 1.0
    - BTC-quoted buy fill with base-asset fee (XRPBTC, fee_asset=XRP, rate=90000) -> cost_eur correct with qty reduced by fee, rate = 90000
    - break_even_eur with qty_base_initial == 0 -> None
    - break_even_eur with cost_eur == None -> None
    - Backward compatibility: existing callers without quote_to_eur_rate param still work (EUR-quoted auto-detect, non-EUR get None)
