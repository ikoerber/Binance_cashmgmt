  <name>Task 1: Alert API endpoints (GET list + PATCH acknowledge)</name>
  <files>backend/app/api/routes/alerts.py, backend/app/main.py</files>
  <action>
Create `backend/app/api/routes/alerts.py` with an APIRouter at prefix `/api/alerts`:

**GET `/{user_id}`** — List alerts for user:
- Query params: `include_acknowledged: bool = False` (default: only unacknowledged), `limit: int = Query(50, ge=1, le=200)`, `offset: int = Query(0, ge=0)`
- Query AlertEventDB filtered by user_id, ordered by created_at DESC
- When include_acknowledged=False: filter `acknowledged == False`
- Return: `{ "alerts": [...], "total": int, "unacknowledged_count": int }`
- Each alert dict: `{ "id", "alert_type", "severity", "title", "details": details_json, "acknowledged", "acknowledged_at", "created_at", "reconciliation_run_id" }`
- Format created_at and acknowledged_at as ISO strings
- unacknowledged_count is always the total count of unacknowledged alerts (regardless of include_acknowledged filter)

**PATCH `/{alert_id}/acknowledge`** — Acknowledge/dismiss a single alert:
- Read alert by id, verify user_id matches (IDOR protection via query param `user_id: str`)
- Set `acknowledged = True`, `acknowledged_at = utcnow()`
- Return the updated alert dict
- 404 if not found or user mismatch

**POST `/{user_id}/acknowledge-all`** — Bulk acknowledge all unacknowledged alerts:
- Update all AlertEventDB where user_id matches and acknowledged=False
- Set acknowledged=True, acknowledged_at=utcnow()
- Return `{ "acknowledged_count": int }`

Follow existing route patterns: wrap in try/except, use `logger.exception()` for errors, return generic error messages. Import `require_api_key` is handled at router level in main.py.

Register the router in `backend/app/main.py`:
- Import: `from app.api.routes.alerts import router as alerts_router`
- Add: `app.include_router(alerts_router, dependencies=[Depends(require_api_key)])` alongside existing routers
