Test categories (target ~35-45 tests):

1. **BacktestConfig validation** (3-4 tests):
   - Valid config creates successfully
   - Invalid fee_rate (negative) raises ValueError
   - Invalid position_fraction (0 or >1) raises ValueError
   - Warmup candle count computed correctly from max(zscore_window, leadlag_window, hurst_lookback, atr_period+1) + 10

2. **Warmup period** (3 tests):
   - No trades generated during warmup period
   - First possible trade is at warmup_end_index
   - warmup_end_index included in BacktestResult

3. **Signal generation and trade entry** (5-6 tests):
   - LONG signal above threshold opens a trade (long-only, per user decision)
   - NEUTRAL/SHORT signal does NOT open a trade (long-only)
   - New LONG signal while position already open is ignored (single position per symbol)
   - Trade entry records: entry_time, entry_price (close + slippage), entry_alpha_score, position_size
   - Position size = current_equity * position_fraction (compounding, per user decision)
   - Entry fee deducted: entry_cost = entry_price * qty * (1 + fee_rate)

4. **Trailing stop exit** (5-6 tests):
   - Trade exits when candle low <= trailing stop level
   - Exit price = trailing stop level (not candle close) minus slippage
   - Exit fee deducted: exit_proceeds = exit_price * qty * (1 - fee_rate)
   - Trailing stop ratchets up as price increases (using update_trailing_stop from alpha_score.py)
   - Trade P&L = exit_proceeds - entry_cost (Decimal)
   - Trade record includes: entry_time, exit_time, entry_price, exit_price, pnl_eur, pnl_pct, duration_candles, alpha_score_at_entry

5. **Equity curve** (3-4 tests):
   - Equity starts at initial_capital
   - Equity updates after each trade close
   - Equity point recorded at each candle: (timestamp, equity, benchmark_equity, drawdown_pct)
   - Equity curve downsampled to daily granularity for storage (max ~730 points for 24 months)

6. **Performance metrics** (5-6 tests):
   - net_return_pct = (final_equity - initial_capital) / initial_capital * 100
   - Sharpe ratio: annualized (365 days for crypto), risk-free=0, Decimal precision (math.sqrt only for annualization factor)
   - Sharpe returns None when std=0 or fewer than 2 data points
   - max_drawdown_pct from high-water-mark tracking
   - win_rate = winning_trades / total_trades * 100 (None if 0 trades)
   - trade_count matches actual trades list length
   - total_fees and total_slippage tracked as separate Decimal cumulative sums

7. **Monthly returns** (2-3 tests):
   - Monthly return computed as equity change per calendar month
   - Returns list of {year, month, return_pct} dicts
   - Handles partial first/last month correctly

8. **Benchmark** (4-5 tests):
   - 50/50 BTC/XRP HODL computed from first candle's close price
   - Benchmark buys at start: 50% capital into BTC, 50% into XRP (in EUR terms, using btceur_candles and xrpeur_candles)
   - Same fee_rate applied on initial benchmark purchase
   - Benchmark equity tracked at each candle (mark-to-market)
   - excess_return_pct = strategy_return - benchmark_return
   - relative_sharpe = strategy_sharpe - benchmark_sharpe (or None if either is None)

9. **Degraded Alpha Score** (2-3 tests):
   - Only Z-Score and Lead-Lag factors active (orderbook + funding marked "unavailable")
   - Alpha Score renormalizes weights correctly (existing compute_alpha_score handles this)
   - Trades still generated from 2-factor partial score

10. **Cancellation** (2 tests):
    - When cancel_event is set, simulation stops and returns partial result
    - Partial result has metrics computed from trades so far

11. **Edge cases** (2-3 tests):
    - Empty candle data returns zero-trade result with initial_capital equity
    - All candles within warmup returns zero-trade result
    - Single trade that never exits (still open at end) is marked as open_trade in result

class BacktestConfig:
    symbol: str
    initial_capital: Decimal
    position_fraction: Decimal       # e.g. Decimal("0.10") = 10% per trade

**Key functions:**

1. `compute_warmup_period(config: BacktestConfig) -> int`:
   Returns `max(config.zscore_window, config.leadlag_window, config.hurst_lookback, config.atr_period + 1) + 10`

2. `compute_sharpe_ratio(daily_equities: List[Decimal], annualization: int = 365) -> Optional[Decimal]`:
   Pure Decimal computation. Returns None if std=0 or <2 points. Use `math.sqrt(annualization)` converted to Decimal for the annualization factor.

3. `compute_max_drawdown(equity_curve: List[Decimal]) -> Decimal`:
   High-water-mark algorithm in Decimal.

4. `compute_monthly_returns(equity_curve: List[EquityPoint]) -> List[MonthlyReturn]`:
   Group equity points by (year, month), compute return per month.

5. `compute_benchmark(btceur_candles: List[dict], xrpeur_candles: List[dict], initial_capital: Decimal, fee_rate: Decimal, start_index: int) -> Tuple[List[Decimal], BenchmarkResult]`:
   50/50 buy at start_index close prices. Track mark-to-market at each candle. Same fee_rate on initial purchase. Return equity list + final result.

6. `run_alpha_backtest(xrpbtc_candles: List[dict], btceur_candles: List[dict], xrpeur_candles: List[dict], config: BacktestConfig, progress_callback: Optional[Callable] = None, cancel_event: Optional[threading.Event] = None) -> BacktestResult`:
   Main simulation loop:
   - Compute warmup period. Validate candle data length.
   - Initialize equity = initial_capital, position = None, trailing_stop_state = None
   - For each candle from warmup_end to end:
     a. Compute Alpha Score using only Z-Score and Lead-Lag factors (mark imbalance + funding as "unavailable"). Call `compute_zscore_mean_reversion()` with `xrpbtc_candles[:i+1]` closes, `compute_leadlag_momentum()` with `btceur_candles[:i+1]` and matching XRP closes, `compute_hurst_rs()` with price history, then `compute_alpha_score()` with factors.
     b. Compute ATR via `compute_atr_standalone()` from candle highs/lows/closes.
     c. If no position and signal == "LONG": open trade. Entry price = close * (1 + slippage_pct). Position size = equity * position_fraction / entry_price. Deduct entry fee.
     d. If position open: update trailing stop via `update_trailing_stop()`. If candle low <= stop_level: close trade. Exit price = stop_level * (1 - slippage_pct). Compute P&L.
     e. Record equity point (downsample to daily later).
     f. Call progress_callback periodically (every 250ms worth of candles, not every candle).
     g. Check cancel_event.is_set() — if true, break and return partial result.
   - Compute metrics from trades list and equity curve.
   - Compute benchmark alongside.
   - Downsample equity curve to daily granularity before returning.
   - Return BacktestResult.

**Critical implementation details:**
- ALL financial math in Decimal. Never use float for prices, equity, P&L, fees. Only exception: `math.sqrt(365)` for Sharpe annualization factor, immediately converted back to Decimal.
- Candle dicts expected format: `{"open_time": datetime, "open": Decimal, "high": Decimal, "low": Decimal, "close": Decimal, "volume": Decimal}` — same format as orderblock candle dicts.
- For Alpha Score computation in backtest: create AlphaFactorScore entries where orderbook and funding have quality="unavailable" and sub_score=Decimal("0"). This triggers existing renormalization in compute_alpha_score().
- Progress callback signature: `callback(candles_processed: int, candles_total: int, trades_found: int)`. Throttle to every ~100 candles to avoid flooding.
- XRP/EUR conversion for equity tracking when backtesting XRPBTC: use xrpeur_candles for mark-to-market of XRP positions. For BTCEUR and XRPEUR symbols, the candle prices are directly in EUR.
- The `run_alpha_backtest` function determines the "trading price" candle set based on symbol: for BTCEUR, trade on btceur_candles; for XRPEUR, trade on xrpeur_candles. xrpbtc_candles + btceur_candles are always needed for Alpha Score computation (Z-Score needs XRPBTC ratio, Lead-Lag needs both).
