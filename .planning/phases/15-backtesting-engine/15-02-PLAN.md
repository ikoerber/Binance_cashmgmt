```python
def _fetch_klines_paginated(self, symbol, interval, start_time, end_time):
    client = get_binance_public_client()
    all_klines = []
    current_start = int(start_time.timestamp() * 1000)
    end_ms = int(end_time.timestamp() * 1000)
    while current_start < end_ms:
        klines = client.get_klines(symbol, interval, limit=1000, start_time=current_start, end_time=end_ms)
        if not klines:
            break
        all_klines.extend(klines)
        current_start = int(klines[-1][6]) + 1
        if len(klines) < 1000:
            break
    return [parse_binance_kline(k) for k in all_klines]
```

```python
class AlphaBacktestRunDB(Base):
    """
    Alpha Backtest Run - Immutable snapshot of Alpha Score backtest results.

    Separate from BacktestRunDB (Orderblock backtests) to avoid confusion.
    """

    __tablename__ = "alpha_backtest_runs"

    id = Column(String, primary_key=True)                           # "abt_{uuid_hex[:12]}"
    user_id = Column(String, ForeignKey("users.id"), nullable=False)
    symbol = Column(String, nullable=False)                          # "BTCEUR" | "XRPEUR"
    interval = Column(String, nullable=False)                        # "5m" | "15m" | "1h"

    data_start = Column(DateTime, nullable=False)
    data_end = Column(DateTime, nullable=False)
    candle_count = Column(Numeric(precision=10, scale=0), nullable=False)
    initial_capital = Column(Numeric(precision=20, scale=2), nullable=False)

    # Key metrics (queryable without JSON parsing)
    net_return_pct = Column(Numeric(precision=20, scale=4), nullable=True)
    sharpe_ratio = Column(Numeric(precision=10, scale=4), nullable=True)
    max_drawdown_pct = Column(Numeric(precision=10, scale=4), nullable=True)
    trade_count = Column(Numeric(precision=10, scale=0), nullable=True)
    win_rate = Column(Numeric(precision=10, scale=4), nullable=True)
    total_fees = Column(Numeric(precision=20, scale=8), nullable=True)
    total_slippage = Column(Numeric(precision=20, scale=8), nullable=True)

    # Benchmark
    benchmark_return_pct = Column(Numeric(precision=20, scale=4), nullable=True)
    excess_return_pct = Column(Numeric(precision=20, scale=4), nullable=True)

    # Sweep reference (NULL for single runs)
    sweep_id = Column(String, nullable=True)

    # JSON blobs
    config_json = Column(JSON, nullable=False)
    metrics_json = Column(JSON, nullable=False)
    trades_json = Column(JSON, nullable=False)
    equity_curve_json = Column(JSON, nullable=False)      # [{t, equity, benchmark, drawdown_pct}]
    monthly_returns_json = Column(JSON, nullable=True)     # [{year, month, return_pct}]

    created_at = Column(DateTime, nullable=False, default=_utcnow)

    __table_args__ = (
        Index("idx_alpha_bt_user_symbol", "user_id", "symbol"),
        Index("idx_alpha_bt_sweep", "sweep_id"),
    )
```

**1. Create `backend/app/services/backtest_data_service.py`:**

Singleton service (following AlphaScoreDataService pattern):

```python
class BacktestDataService:
    """Orchestrates Alpha Score backtesting: data fetch, simulation, persistence."""

    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._initialized = False
        return cls._instance

    def __init__(self):
        if self._initialized:
            return
        self._initialized = True
        self._active_runs = {}   # run_id -> threading.Event (for cancellation)
```

**Key methods:**

a. `_fetch_candles_paginated(self, symbol: str, interval: str, start_time: datetime, end_time: datetime) -> List[dict]`:
   - Reuse the paginated kline fetch pattern from OrderblockDataService.
   - Parse raw Binance klines into dicts with `{"open_time": datetime, "open": Decimal, "high": Decimal, "low": Decimal, "close": Decimal, "volume": Decimal}`.
   - Use `get_binance_public_client()` for API calls.
   - INTERVAL_MS dict for interval-to-milliseconds conversion.

b. `_compute_warmup_start(self, user_start: datetime, interval: str, warmup_candles: int) -> datetime`:
   - Subtract `warmup_candles * interval_ms` from user_start to get the actual fetch start time.

c. `async def run_backtest(self, user_id: str, symbol: str, months: int, initial_capital: Decimal, config_overrides: dict, db: Session, ws_manager=None) -> dict`:
   - Determine interval from user settings (alpha_score_interval, default "15m").
   - Build BacktestConfig from user settings + config_overrides.
   - Compute warmup period and fetch start time.
   - Fetch 3 candle series: XRPBTC, BTCEUR, and XRPEUR (or derive XRPEUR from XRPBTC * BTCEUR if unavailable).
   - Run data fetch in `asyncio.to_thread()` (blocking I/O).
   - Create cancel_event, store in `self._active_runs[run_id]`.
   - Create progress_callback that sends WebSocket messages via `ws_manager._broadcast_to_user()` (throttled to 2-4/sec).
   - Run `run_alpha_backtest()` in `asyncio.to_thread()` with progress callback and cancel event.
   - Persist result to AlphaBacktestRunDB via `_save_result()`.
   - Remove from `self._active_runs`.
   - Return serialized result dict.

d. `_save_result(self, db: Session, user_id: str, result: BacktestResult) -> str`:
   - Generate ID: `f"abt_{uuid.uuid4().hex[:12]}"`.
   - Serialize config, metrics, trades, equity_curve, monthly_returns to JSON (converting Decimal to str for JSON safety).
   - Create AlphaBacktestRunDB, flush, return run_id.

e. `def cancel_run(self, run_id: str) -> bool`:
   - Set the cancel_event for the given run_id. Return True if found.

f. `def get_runs(self, db: Session, user_id: str, symbol: Optional[str] = None) -> List[dict]`:
   - Query AlphaBacktestRunDB filtered by user_id (and symbol if provided), ordered by created_at desc.
   - Return list of summary dicts (no trades_json or equity_curve_json — those are large).

g. `def get_run_detail(self, db: Session, user_id: str, run_id: str) -> Optional[dict]`:
   - Query single run with full JSON columns.
   - Return None if not found or wrong user_id (IDOR protection).

**Serialization helpers:**
- `_serialize_config(config: BacktestConfig) -> dict`
- `_serialize_metrics(metrics: BacktestMetrics) -> dict`
- `_serialize_trade(trade: TradeRecord) -> dict`
- `_serialize_equity_point(point: EquityPoint) -> dict`
- All Decimal values converted to `str()` for JSON (consistent with project pattern).

```python
router = APIRouter(prefix="/api/backtest", tags=["backtest"])
```

Endpoints:

a. `POST /api/backtest/{user_id}/run`:
   - Body: `{"symbol": "BTCEUR", "months": 12, "initial_capital": "10000", "fee_rate": "0.001", "slippage_pct": "0.0005", "position_fraction": "0.10", ...optional config overrides}`
   - Validates: symbol in KNOWN_PAIRS, months 1-24, initial_capital > 0, fee_rate/slippage_pct non-negative
   - Calls `service.run_backtest()` with db session and ws_manager
   - Returns 200 with `{"run_id": "...", "metrics": {...}, "trades": [...], "equity_curve": [...], ...}`
   - Error handling: try/except with `logger.exception()` and generic error response (per project convention)

b. `GET /api/backtest/{user_id}/runs`:
   - Query params: `?symbol=BTCEUR` (optional)
   - Returns list of run summaries (id, symbol, interval, created_at, key metrics — no trades/equity)
   - Ordered by created_at desc

c. `GET /api/backtest/{user_id}/runs/{run_id}`:
   - Returns full run detail including trades_json, equity_curve_json, monthly_returns_json
   - 404 if not found or wrong user_id

d. `POST /api/backtest/{user_id}/cancel/{run_id}`:
   - Calls `service.cancel_run(run_id)`
   - Returns 200 with `{"cancelled": true}` or 404

All routes use `Depends(get_db)` for database session. All routes follow existing error sanitization pattern (generic messages, `logger.exception()`).
