**3. HealthCheckService class (singleton with double-checked locking):**
- `__init__`: `self._lock = threading.Lock()`, `self._cached_result: Optional[CachedValue] = None`
- `async get_health() -> dict`: Check `_cached_result.is_expired(now)` under lock. If fresh, return cached. If stale, run `_run_all_checks()` and store new `CachedValue` with 5s TTL.
- `async _run_all_checks() -> dict`: `asyncio.gather()` all 8 checks with `return_exceptions=True`. Map exceptions to error status. Build response dict with `services: dict[str, ServiceStatus]` and `overall_status`.
- 8 async check methods, each returning `ServiceStatus`:

  a. `_check_backend()`: Always returns `ok` (if this code runs, backend is alive).

  b. `_check_db()`: Import `engine` from `app.db.database`. If None, return `unavailable`. Use `engine.connect()` + `text("SELECT 1")` (read-only, NOT `get_db()`). Success = `ok`, Exception = `error`.

  c. `_check_websocket()`: `get_stream_manager().get_stats()`. `not running` = `stopped`. Running but empty `current_prices` = `degraded`. Running + has prices = `ok`.

  d. `_check_dry_run()`: `get_dry_run_service()._running`. True = `ok`, False = `stopped`.

  e. `_check_alpha_score()`: Read `_kline_cache` under `service._lock`. Empty = `unavailable`. Any `CachedValue` not expired = `ok`. All expired but not stale = `degraded`. All stale = `stale`.

  f. `_check_sentiment()`: Read `_history_initialized` + `_cache` under `service._lock`. Not initialized = `unavailable`. Initialized + any live cache = `ok`. Initialized + all expired = `stale`.

  g. `_check_macro()`: Read `_cache` under `service._lock`. Empty = `unavailable`. Any live = `ok`. All expired = `stale`.

  h. `_check_binance_rest()`: Wrap `get_binance_public_client().get_ticker_price("BTCEUR")` with `asyncio.wait_for(asyncio.to_thread(...), timeout=2.0)`. Success = `ok`. TimeoutError or Exception = `error`.

**4. Singleton pattern (match existing):**
```python
_service_instance: Optional[HealthCheckService] = None
_service_lock = threading.Lock()

def get_health_check_service() -> HealthCheckService:
    global _service_instance
    if _service_instance is None:
        with _service_lock:
            if _service_instance is None:
                _service_instance = HealthCheckService()
    return _service_instance
```

```python
        ...  # 8 total

}
```

- Do NOT write to AlertEventDB (health events are in-memory only)
- Do NOT use `asyncio.Lock` — use `threading.Lock` to match existing singleton pattern
