## Goal

User can navigate to a dedicated full-page Chart page from the Trading nav group that displays an interactive OHLCV candlestick chart with volume histogram for the current symbol. The chart fills the remaining viewport below the sub-nav bar. Interval buttons (15m, 1h, 4h, 1d, 1w) and lookback presets are rendered as a floating toolbar over the chart. The chart polls periodically to keep the latest candle current.

## Context

### User Decisions (from 25-CONTEXT.md — NON-NEGOTIABLE)

- Chart fills remaining viewport below sub-nav — no fixed height, resizes with browser window
- Chart only — no additional header, info bar, or sidebar
- Volume histogram overlaid behind candles (semi-transparent, same pane) — matches OrderblockChart
- Top-right floating toolbar — interval buttons + lookback controls, TradingView-style minimal
- Intervals: 15m, 1h, 4h, 1d, 1w (user explicitly requested 15m and 1w additions beyond roadmap minimum)
- Default interval: 1h
- Lookback: Claude's discretion — presets or dropdown, whatever fits toolbar
- Live updates: Poll for latest candle periodically (e.g. every 30s), no full refetch
- Data source: Reuse existing `/api/orderblock/{user_id}/candles` endpoint with `start_time + end_time` mode
- No new backend endpoint needed
- Chart link in Trading nav group after TradeLots: Trading -> Dashboard, TradeLots, Chart
- Route: `/s/:symbol/chart`

### Existing Code to Reuse

- `OrderblockChart.jsx` — template for lightweight-charts setup (createChart, CandlestickSeries, HistogramSeries, volume coloring, ResizeObserver, dark theme, TZ_OFFSET_SEC)
- `useChartTheme` hook + `hexToRgb` — chart color bridge from CSS variables
- `getOrderblockCandles()` API — already supports `start_time + end_time` mode
- `useSymbol()` / `useUser()` contexts — provide symbol and userId

### Backend Gap

`INTERVAL_MS` in `orderblock_data_service.py` currently has: 1m, 5m, 15m, 30m, 1h, 4h, 1d. Missing: `1w`. Must add `"1w": 604_800_000` so the candles endpoint validates the 1w interval.

<task id="25-01-T3" title="Create Chart.jsx component with full-page candlestick chart, floating toolbar, and live polling">

**File:** `frontend/src/components/Chart.jsx`

Create the main Chart page component. This is the core implementation task.

**Structure:**

```
Chart.jsx
├── State: selectedInterval (default "1h"), lookbackMonths (default 1), candles[]
├── Floating Toolbar (top-right, absolute positioned over chart)
│   ├── Interval buttons: 15m | 1h | 4h | 1d | 1w
│   └── Lookback presets: 1W | 1M | 3M | 6M (or similar)
├── Chart container (fills remaining viewport)
│   ├── CandlestickSeries (main price data)
│   └── HistogramSeries (volume, semi-transparent, same pane, behind candles)
└── Polling effect (30s interval, updates/appends latest candle only)
```

**Implementation details:**

1. **Imports:** `createChart`, `CandlestickSeries`, `HistogramSeries`, `ColorType`, `CrosshairMode` from `lightweight-charts`. `useChartTheme`, `hexToRgb` from hooks. `getOrderblockCandles` from API client. `useSymbol`, `useUser` from contexts.

2. **State:**
   - `selectedInterval` — string, default `"1h"`
   - `lookback` — string key like `"1W"`, `"1M"`, `"3M"`, `"6M"` — default `"1M"`
   - Use TanStack Query (`useQuery`) to fetch candles with `start_time` and `end_time` computed from lookback selection

3. **Lookback-to-time conversion:** Map lookback presets to a start time:
   - `"1W"` → 7 days ago
   - `"1M"` → 1 month ago
   - `"3M"` → 3 months ago
   - `"6M"` → 6 months ago
   - End time = now

4. **Data fetching:** Call `getOrderblockCandles(userId, { symbol, interval: selectedInterval, startTime: start.toISOString(), endTime: end.toISOString(), contextCandles: 20 })`. Refetch when interval or lookback changes.

5. **Chart creation (useEffect on theme):**
   - `createChart(container, { ... })` — match OrderblockChart pattern for layout, grid, crosshair, timeScale
   - **Critical difference from OrderblockChart:** Height must fill viewport. Compute height as `window.innerHeight - container.getBoundingClientRect().top - footerHeight` (or use CSS `height: calc(100vh - <offset>)` on the container and read clientHeight). Use ResizeObserver + window resize listener to keep height dynamic.
   - Add CandlestickSeries with theme colors (upColor, downColor, border, wick colors)
   - Add HistogramSeries for volume with `priceScaleId: 'volume'`, `scaleMargins: { top: 0.82, bottom: 0 }` — semi-transparent, color-matched to candle direction

6. **Data update (useEffect on candles):**
   - Apply TZ_OFFSET_SEC to all candle timestamps (same pattern as OrderblockChart)
   - `candleSeries.setData(adjusted)` for candles
   - `volumeSeries.setData(...)` with per-candle directional coloring: `rgba(profit, 0.3)` for bullish, `rgba(loss, 0.3)` for bearish
   - `chart.timeScale().fitContent()`

7. **Live polling (useEffect):**
   - Set up a 30-second interval timer
   - On each tick: fetch the last candle only by using `startTime` = 2 intervals ago, `endTime` = now, `contextCandles` = 20 (minimum the endpoint allows)
   - Use `candleSeries.update(latestCandle)` and `volumeSeries.update(latestVolumeBar)` to update in-place (lightweight-charts `update()` method updates the last bar if time matches, or appends if new)
   - Clear interval on cleanup

8. **Floating Toolbar:**
   - Absolute positioned `div` in top-right corner of chart container (the parent `div` must be `position: relative`)
   - Interval buttons: `["15m", "1h", "4h", "1d", "1w"]` — highlight active with accent style
   - Lookback presets: `["1W", "1M", "3M", "6M"]` — highlight active
   - Semi-transparent dark background, small rounded corners, small font — TradingView-style minimal

9. **Loading state:** Show a centered spinner or "Loading chart..." text while candles are being fetched.

10. **Error state:** Show an error message if candle fetch fails with a retry button.

11. **Cleanup:** On unmount, `chart.remove()`, disconnect ResizeObserver, clear polling interval.

**Verify:** Chart renders full-page with candles and volume. Toolbar allows switching intervals and lookback. Chart updates every 30s with latest candle.

</task>
