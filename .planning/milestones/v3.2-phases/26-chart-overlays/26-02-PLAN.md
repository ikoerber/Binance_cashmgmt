## Goal

User can see open sell order prices as horizontal lines on the chart, with orders at similar prices clustered into a single thicker line with a count badge. User can see active trailing stop levels on the chart when a dry-run or bot is active. Both overlay types are individually toggleable via buttons in the floating toolbar, visually distinguishable from zones and break-even, and on by default.

## Context

### User Decisions (from 26-CONTEXT.md -- NON-NEGOTIABLE)

- Sell orders: Clustered/grouped lines -- orders within a small price range merged into a single thicker line with count badge (e.g., "3 orders"), not individual lines per order
- Trailing stop: Distinct style that signals "dynamic level" (this moves with price)
- All overlay types must be visually distinct from each other and from candles/volume
- All overlays on by default
- Each overlay type individually toggleable via buttons in the floating toolbar

- Theme colors available: `accentAmber` (#fbbf24), `chart1` (#818cf8, purple), `chart5` (#a78bfa, light purple)

### Visual Design Decisions

**Sell Order Lines:**
- Color: Amber/gold (`accentAmber` / `#fbbf24`) -- warm color clearly distinct from green zones, red zones, and blue break-even
- Style: `LineStyle.Solid` with `lineWidth: 2` -- solid lines stand out from dashed zones and dotted break-even
- Clustering: Orders within 0.5% of each other are grouped. Title shows count (e.g., "3 Orders @ 2,450"). Single orders show "Sell @ 2,400"
- `axisLabelVisible: true` so the sell price is visible on the price axis

**Trailing Stop Lines:**
- Color: Purple (`chart1` / `#818cf8`) -- unique color not used by other overlays
- Style: `LineStyle.SparseDotted` with `lineWidth: 2` -- sparse dots signal "dynamic/moving level"
- Title: "Trail Stop" (or "Trail Stop (frozen)" if frozen)
- Only shown when trailing stop data exists for the current symbol. If no stop level, the toggle button still appears but no line is drawn (graceful empty state).
- `axisLabelVisible: true`

### Clustering Algorithm

Group sell orders by price proximity:
1. Sort orders by price ascending
2. Walk through sorted list. If current price is within 0.5% of the cluster's average price, add to cluster. Otherwise start a new cluster.
3. Each cluster renders as one price line at the average price, with title showing order count.

**1. Add a clustering helper function** (place above the Chart component, after the existing utility functions like `computeTimeRange` and `intervalMs`):

```js
/**
 * Cluster sell orders by price proximity.
 * Orders within `thresholdPct` (0.5%) of the running cluster average are grouped.
 * Returns array of { avgPrice, count, orders }.
 */
function clusterOrders(orders, thresholdPct = 0.005) {
  if (!orders?.length) return [];

  const sorted = [...orders]
    .map((o) => ({ ...o, priceNum: parseFloat(o.price) }))
    .filter((o) => o.priceNum > 0 && isFinite(o.priceNum))
    .sort((a, b) => a.priceNum - b.priceNum);

  const clusters = [];
  let current = { sum: sorted[0].priceNum, count: 1, orders: [sorted[0]] };

  for (let i = 1; i < sorted.length; i++) {
    const avg = current.sum / current.count;
    if (Math.abs(sorted[i].priceNum - avg) / avg <= thresholdPct) {
      current.sum += sorted[i].priceNum;
      current.count += 1;
      current.orders.push(sorted[i]);
    } else {
      clusters.push({
        avgPrice: current.sum / current.count,
        count: current.count,
        orders: current.orders,
      });
      current = { sum: sorted[i].priceNum, count: 1, orders: [sorted[i]] };
    }
  }
  clusters.push({
    avgPrice: current.sum / current.count,
    count: current.count,
    orders: current.orders,
  });

  return clusters;
}
```

// --- Sell Order Lines (clustered) ---
if (showSellOrders && ordersData?.orders) {
  const clusters = clusterOrders(ordersData.orders);
  for (const cluster of clusters) {
    const title = cluster.count > 1
      ? `${cluster.count} Orders`
      : 'Sell';
    overlayLinesRef.current.push(
      series.createPriceLine({
        price: cluster.avgPrice,
        color: theme.accentAmber,
        lineWidth: cluster.count > 1 ? 2 : 1,
        lineStyle: LineStyle.Solid,
        axisLabelVisible: true,
        title,
      })
    );
  }
}

// --- Trailing Stop Level ---
if (showTrailingStop && trailingData?.stops) {
  const symbolStop = trailingData.stops[symbol];
  if (symbolStop?.stop_level) {
    const stopPrice = parseFloat(symbolStop.stop_level);
    if (stopPrice > 0 && isFinite(stopPrice)) {
      const isFrozen = symbolStop.frozen;
      overlayLinesRef.current.push(
        series.createPriceLine({
          price: stopPrice,
          color: theme.chart1,
          lineWidth: 2,
          lineStyle: LineStyle.SparseDotted,
          axisLabelVisible: true,
          title: isFrozen ? 'Trail Stop (frozen)' : 'Trail Stop',
        })
      );
    }
  }
}
