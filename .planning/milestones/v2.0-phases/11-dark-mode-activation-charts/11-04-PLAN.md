The English-style names like 'STARK LONG' are used elsewhere (e.g., `data.direction.recommendation` for the macro sub-signal), but `data.action` is the combined action label in German. You MUST use the German strings as map keys.

**Step 1:** Add an `ACTION_COLOR_MAP` object inside the component body (after the existing `MACRO_REC_COLORS` on line 30-36, same pattern), mapping the backend `data.action` German values to theme-aware colors:

```javascript
  'Aggressiv kaufen': theme.actionStrongBuy,

  'Leicht reduzieren': theme.actionLeanSell,
  'Verkaufen': theme.actionSell,

```

Create a helper variable for easy reuse:
