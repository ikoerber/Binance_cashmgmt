# Requirements: BTC/EUR Cashflow-Management

**Defined:** 2026-02-28
**Core Value:** Ledger-first, deterministisches, auditierbares Cashflow-Tracking und automatisiertes Trading-System

## v3.2 Requirements

Requirements for v3.2 UX Improvements. Each maps to roadmap phases.

### Chart

- [x] **CHART-01**: User can navigate to a dedicated full-page OHLCV candlestick chart for the current symbol in the Trading nav group
- [x] **CHART-02**: User can select chart interval (1h, 4h, 1d) and lookback period
- [x] **CHART-03**: User can see orderblock zones as shaded overlays on the chart
- [x] **CHART-04**: User can see their portfolio break-even price as a horizontal line on the chart
- [x] **CHART-05**: User can see open sell order prices as horizontal lines on the chart
- [x] **CHART-06**: User can see active trailing stop levels on the chart (when dry-run/bot active)
- [x] **CHART-07**: Chart displays volume histogram below the price chart

### Navigation

- [x] **NAV-01**: User sees the sub-navigation (Trading/Analyse/Bot/Admin groups) on Settings, Status, and Backtest pages
- [x] **NAV-02**: User only sees symbols in GlobalNav that have a positive Binance balance
- [x] **NAV-03**: User only sees symbols in Overview page that have a positive Binance balance

### Overview

- [ ] **OVER-01**: Overview displays one card per crypto asset (consolidated, not per trading pair)
- [ ] **OVER-02**: User can see their BNB balance and current EUR value in the Overview
- [ ] **OVER-03**: User can see recent BNB fee deductions (how much BNB was consumed by the last trade's fees)
- [ ] **OVER-04**: Backtest page shows an expandable explainer section describing Walk-Forward backtesting methodology
- [ ] **OVER-05**: Backtest page parameter inputs include descriptions explaining what each parameter controls

## Future Requirements

### Performance

- **PERF-01**: Loading skeletons for chart and data-heavy pages
- **PERF-02**: Reduced re-renders on live price updates

### Mobile

- **MOBI-01**: Responsive layout for tablet/phone

## Out of Scope

| Feature | Reason |
|---------|--------|
| Full BNBEUR trading pair (lots, orders, sync) | BNB is fee token, not actively traded — balance display only |
| Light/Dark toggle | Dark-only established in v2.0 |
| Mobile-first responsive design | Desktop-focused application |
| TradingView widget (external embed) | Using lightweight-charts library already in codebase |
