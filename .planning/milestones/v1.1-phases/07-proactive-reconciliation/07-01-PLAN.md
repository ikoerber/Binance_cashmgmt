```python
def evaluate_discrepancies(
    balance_report: dict,
    order_report: dict,
    tolerance_base: Decimal,
    tolerance_quote: Decimal,
) -> list[dict]:
```

Pure function (no I/O). Takes reconciliation sub-reports and thresholds, returns list of alert dicts ready for AlertEventDB creation.

Logic:
- Check `balance_report["base"]["diff"]` against tolerance_base (compare as Decimal, > not >=)
- Check `balance_report["quote"]["diff"]` against tolerance_quote
- Check `balance_report.get("errors", [])` — each error -> critical alert
- Check `order_report.get("discrepancies", [])` — each discrepancy -> warning alert
- Return list of alert dicts (empty list if no discrepancies)

Balance discrepancy severity:
- diff > tolerance * 10 -> "critical"
- diff > tolerance -> "warning"

Handle missing keys gracefully (empty dict -> no alerts).
