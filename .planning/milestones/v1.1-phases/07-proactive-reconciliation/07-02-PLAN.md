1. **Add `run_and_persist()` method:**
   ```python
   def run_and_persist(
       self,
       db: Session,
       user_id: str,
       symbol: str,
       trigger: str,  # "manual", "post_sync", "post_full_sync"
       tolerance_base: Decimal = Decimal("0.0001"),
       tolerance_quote: Decimal = Decimal("1.00"),
   ) -> Dict[str, Any]:
   ```

   Logic:
   - Run `reconcile_balances(db, user_id, symbol, tolerance_base, tolerance_quote)` — always run balances
   - Run `reconcile_orders(db, user_id, symbol)` — always run orders
   - Do NOT run reconcile_fills here (fills are already synced by the calling sync endpoint — running fills again would be redundant and could cause issues)
   - Combine into report dict: `{"balances": balance_report, "orders": order_report}`
   - Call `evaluate_discrepancies(balance_report, order_report, tolerance_base, tolerance_quote)` from domain
   - Determine `status`: "failed" if any report has errors, "completed" otherwise
   - Determine `has_discrepancies`: True if evaluate_discrepancies returns non-empty list
   - Create `ReconciliationRunDB` row (generate UUID with `str(uuid.uuid4())`): user_id, symbol, trigger, status, report_json=report, has_discrepancies, created_at
   - For each alert from evaluate_discrepancies: create `AlertEventDB` row with reconciliation_run_id, user_id, alert_type, severity, title, details_json
   - `db.add()` all new objects, `db.flush()` (commit handled by get_db yield pattern)
   - Return dict with: run_id, trigger, status, has_discrepancies, alert_count, report

   Important: Wrap in try/except — if reconciliation fails, log error but do NOT propagate exception to caller (auto-reconciliation should not break sync flow). Return a minimal error report instead.

2. **Add `get_history()` class method or standalone function:**
   ```python
   def get_reconciliation_history(
       self,
       db: Session,
       user_id: str,
       limit: int = 20,
       offset: int = 0,
   ) -> Dict[str, Any]:
   ```
   - Query ReconciliationRunDB filtered by user_id, ordered by created_at DESC
   - Return list of run summaries (id, symbol, trigger, status, has_discrepancies, alert_count, created_at)
   - Include total count for pagination

3. **Add `get_run_detail()` method:**
   ```python
   def get_reconciliation_run(self, db: Session, user_id: str, run_id: str) -> Optional[Dict]:
   ```
   - Query single ReconciliationRunDB by id + user_id (IDOR protection)
   - Include full report_json and associated alert events
   - Return None if not found

4. **Update `full_reconciliation()`** to use `run_and_persist()`:
   - Call `run_and_persist(db, user_id, symbol, trigger="manual")`
   - Also run fills reconciliation separately (only manual full recon includes fills)
   - Combine results maintaining backward-compatible response shape
   - This ensures manual reconciliation also gets persisted

5. **Add `_load_user_thresholds()` helper:**
   - Query UserSettingsDB for user_id
   - Return (tolerance_base, tolerance_quote) tuple with defaults if settings/columns are None

Add imports: `uuid`, `ReconciliationRunDB`, `AlertEventDB`, `UserSettingsDB`, `evaluate_discrepancies` from domain.
