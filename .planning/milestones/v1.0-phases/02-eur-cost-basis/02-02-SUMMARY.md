## Decisions Made
- Separated _get_quote_to_eur_rates() from existing _get_per_fill_fee_conversion_rates() to avoid cache key collisions (Research Pitfall 6 from research phase)
- csv_import_service.py intentionally left unchanged -- the quote_to_eur_rate parameter defaults to None for backward compatibility, and non-EUR CSV lots are backfilled via backfill_cost_eur.py (same pattern as fee_eur_value backfill)
- Alembic migration cleaned up to only include new columns + backfill (removed autogenerated false positives from SQLite type detection)
- WebSocket handler fetches rate inline (not via SyncService) since it operates outside the batch sync flow
