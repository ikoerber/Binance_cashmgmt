<objective>
Integrate EUR cost basis through the full stack: DB schema, Alembic migration, sync service rate fetching, lot service persistence, API response, and backfill script.

Purpose: The domain logic from Plan 01 computes cost_eur from a provided rate, but the rate must be fetched from Binance and persisted in the database. This plan wires the domain logic into the service layer, adds DB columns, creates the migration with EUR-quoted lot backfill, and provides a standalone backfill script for BTC-quoted lots.

Output: Fully functional EUR cost basis pipeline: sync fetches rate -> lot service passes to domain -> domain computes -> service persists to DB -> API exposes to frontend. Migration backfills existing EUR-quoted lots. Backfill script handles BTC-quoted lots.
</objective>

    **2. Backfill script (backend/scripts/backfill_cost_eur.py):**

    Create a standalone script following the exact pattern of `backend/scripts/backfill_fee_eur_value.py`:

    - `--commit` flag (dry-run by default)
    - `--db` flag (pg/sqlite, default pg)
    - Finds all trade_lots with `cost_eur IS NULL` and `symbol NOT IN ('BTCEUR', 'ETHEUR', 'XRPEUR')` (i.e., BTC-quoted lots)
    - For each lot, looks up the `created_from_fill_id` in `ledger_events` to get the fill timestamp
    - Computes `rate_pair = quote_asset + "EUR"` (for XRPBTC: quote is BTC, so "BTCEUR")
    - Fetches historical BTC/EUR price via Binance Klines API at fill timestamp
    - Computes `cost_eur = cost_quote * btceur_rate`
    - Updates `cost_eur` and `quote_to_eur_rate` on the lot
    - Minute-caching for API calls (fills in same minute share one API call)
    - Rate limiting: `time.sleep(0.1)` between unique API calls
    - Progress logging every 50 records
    - Graceful error handling: skip lot on failure with warning, continue

    The script uses raw SQL via SQLAlchemy `text()` (same as backfill_fee_eur_value.py), NOT the ORM models.

    Header docstring:
    ```
    Backfill cost_eur for existing BTC-quoted lots (e.g., XRPBTC).

    The Alembic migration "add EUR cost basis columns to trade_lots" backfills EUR-quoted
    lots (BTCEUR, ETHEUR, XRPEUR) via SQL. BTC-quoted lots need historical API data that
    cannot be computed in migration.

    Usage:
        python scripts/backfill_cost_eur.py              # Dry-run
        python scripts/backfill_cost_eur.py --commit     # Write to DB
    ```
