  <behavior>
    Expected behaviors in testable terms:

    1. BACKWARD COMPATIBILITY (existing tests must pass unchanged):
       - compute_combined_score(direction, sizing) -> identical result to current implementation
       - direction_weight == 0.60, sizing_weight == 0.40 when no alpha

    2. NEW: AlphaInput dataclass:
       - AlphaInput(score=Decimal, trade_signal=str, quality=str, active_factors=int, total_factors=int, threshold=Decimal, factors=list)
       - factors is a list of dicts from alpha_data["factors"] for frontend display

    3. NEW: _normalize_alpha(score: Decimal) -> Decimal:
       - _normalize_alpha(Decimal("5")) -> Decimal("1")
       - _normalize_alpha(Decimal("-5")) -> Decimal("-1")
       - _normalize_alpha(Decimal("0")) -> Decimal("0")
       - _normalize_alpha(Decimal("2.5")) -> Decimal("0.5")
       - _normalize_alpha(Decimal("6")) -> Decimal("1") (clamped)
       - _normalize_alpha(Decimal("-7")) -> Decimal("-1") (clamped)

    4. THREE-SIGNAL SCORING (alpha available, quality not warmup/unavailable):
       - compute_combined_score(direction, sizing, alpha=AlphaInput(score=Decimal("3"), quality="full", ...))
       - direction_weight == 0.50, sizing_weight == 0.30, alpha_weight == 0.20
       - unified_raw = direction_norm * 0.50 + sentiment_dir * 0.30 + alpha_norm * 0.20
       - CombinedScoreResult gains alpha_weight field (Decimal)
       - CombinedScoreResult gains alpha field (Optional[AlphaInput])

    5. FALLBACK (alpha=None or quality in warmup/unavailable):
       - compute_combined_score(direction, sizing, alpha=AlphaInput(quality="warmup", ...))
       - direction_weight == 0.60, sizing_weight == 0.40, alpha_weight == 0.00
       - Identical behavior to no-alpha case

    6. QUALITY with 3 signals:
       - _assess_quality(direction, sizing, alpha) when alpha is valid:
         full: dir_ratio >= 0.75 AND siz_ratio >= 0.6 AND alpha_ratio >= 0.5
       - When alpha None/warmup: exact existing logic

    7. CONFLICT with 3 signals:
       - _detect_conflict(direction_norm, sentiment_dir, alpha_norm) adds optional alpha-vs-macro check:
         when alpha strong AND macro strong in opposite direction -> additional conflict note
       - When alpha None: exact existing conflict logic

    8. SERVICE LAYER:
       - get_combined_score(interval_minutes, symbol, user_id="", settings=None) -> dict
       - When settings provided: fetches alpha score via get_alpha_score_data_service()
       - When alpha fetch fails/times out: alpha_input=None, fallback to 60/40
       - _serialize includes "alpha" key (null when unavailable, object when available)
       - alpha object includes: score, trade_signal, quality, active_factors, total_factors, weight, status, factors (list)

    9. API ROUTE:
       - GET /api/combined/{user_id}/score gains Depends(get_db)
       - Loads user settings via _get_user_settings pattern (from alpha_score route)
       - Passes user_id + settings to service.get_combined_score()
  </behavior>

          def compute_combined_score(direction, sizing, alpha=None):
              # Determine weights
              if alpha is None or alpha.quality in ("warmup", "unavailable"):
                  dir_w, siz_w, alp_w = DIRECTION_WEIGHT, SIZING_WEIGHT, Decimal("0")
                  alpha_normalized = Decimal("0")
              else:
                  dir_w, siz_w, alp_w = DIRECTION_WEIGHT_3, SIZING_WEIGHT_3, ALPHA_WEIGHT_3
                  alpha_normalized = _normalize_alpha(alpha.score)

              # Unified Score: include alpha contribution
              unified_raw = direction_normalized * dir_w + sentiment_direction * siz_w + alpha_normalized * alp_w

              # Confidence: include alpha confidence when available
              # alpha_confidence = alpha_ratio * 1.0 (alpha has no dispersion-like factor)
              if alpha is not None and alpha.quality not in ("warmup", "unavailable"):
                  alpha_ratio = Decimal(str(alpha.active_factors)) / Decimal(str(max(1, alpha.total_factors)))
                  composite_confidence = direction_confidence * dir_w + sizing_confidence * siz_w + alpha_ratio * alp_w
              else:
                  composite_confidence = direction_confidence * DIRECTION_WEIGHT + sizing_confidence * SIZING_WEIGHT

              # Conflict detection: pass alpha_normalized if alpha available
              aligned, conflict_desc = _detect_conflict(
                  direction_normalized, sentiment_direction,
                  alpha_normalized=alpha_normalized if alp_w > 0 else None
              )

              # Quality: pass alpha
              quality, quality_reason = _assess_quality(direction, sizing, alpha=alpha if alp_w > 0 else None)

              # Return with new fields
              return CombinedScoreResult(
                  ...,
                  direction_weight=dir_w,
                  sizing_weight=siz_w,
                  alpha_weight=alp_w,
                  alpha=alpha if alp_w > 0 else None,
                  ...
              )
