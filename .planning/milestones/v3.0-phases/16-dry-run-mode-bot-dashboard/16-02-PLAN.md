**Class DryRunService:**

**State:**
- `_lock: asyncio.Lock` — prevents race between toggle and evaluation
- `_running: bool` — lifespan control
- `_task: Optional[asyncio.Task]` — background evaluation task
- `_active_users: Dict[str, Dict]` — tracks active dry-run users with their settings (loaded from DB on start)

**Lifecycle methods:**
- `async def start()`: Called from main.py lifespan. Sets `_running = True`. Loads active dry-run portfolios from DB. Starts evaluation loop as asyncio.create_task.
- `async def stop()`: Sets `_running = False`. Cancels task.

**Evaluation loop (`async def _evaluation_loop()`):**
Follow Pattern 2 from RESEARCH.md exactly:
1. While `_running`:
   a. Get current UTC time
   b. Determine the minimum interval from all active users (query user settings for `alpha_score_interval`). Default to 15 minutes if no active users.
   c. Calculate seconds until next interval boundary (snap to wall clock: :00, :05, :10, :15, :20, :25, :30, :35, :40, :45, :50, :55 for 5m; :00, :15, :30, :45 for 15m; :00 for 1h)
   d. `await asyncio.sleep(sleep_seconds)`
   e. If not `_running`: break
   f. Query DB for all active dry-run portfolios (`is_active=True`)
   g. For each active user+symbol combination:
      - **Idempotency check**: Query most recent decision for this user+symbol. If its `evaluated_at` is within the current interval, skip.
      - Acquire `_lock`
      - Call `_evaluate_single(user_id, symbol, db_session)`
      - Release lock
   h. **30-day purge**: Delete decisions where `evaluated_at < now - 30 days` (once per loop iteration, not per user)

**_evaluate_single(user_id, symbol, db):**
1. Load user settings (alpha_score_interval, weights, threshold, etc.)
2. Call `get_alpha_score_data_service().get_alpha_score(user_id, symbol, db)` — gets current Alpha Score
3. Load virtual portfolio and positions from DB
4. Get current price from alpha score response or `get_binance_public_client().get_ticker(symbol)`
5. Get trailing stop level from alpha score response
6. Call `determine_action(signal, quality, has_open_position, candle_low=current_price, trailing_stop_level)` from domain module
7. If action == "BUY":
   - Load fee_rate and slippage_pct from user settings (or defaults: 0.001 and 0.0005)
   - Call `compute_position_size()` then `execute_virtual_buy()` from domain
   - Create DryRunPositionDB record
   - Update DryRunPortfolioDB (cash, trade_count)
8. If action == "SELL":
   - Call `execute_virtual_sell()` from domain
   - Delete position from DB
   - Update DryRunPortfolioDB (cash, realized_pnl, win_count if applicable)
9. Create DryRunDecisionDB with full context (all factor scores, Alpha Score, trailing stop, price, action, reason)
10. Update DryRunPortfolioDB equity (call `compute_virtual_equity()` from domain to update total_equity and unrealized_pnl)
11. Broadcast via WebSocket

**serialize_factor_scores(alpha_score_result) -> List[dict]:**
Convert AlphaFactorScore objects to serializable dicts for factors_json column.

**Toggle (`async def toggle_dry_run(user_id, db)`):**
1. Acquire `_lock`
2. Load or create DryRunPortfolioDB for user
3. If activating: set is_active=True, activated_at=now. If portfolio doesn't exist, create with initial_capital from settings.
4. If deactivating: set is_active=False
5. Broadcast dry_run_status via WebSocket
6. Release lock
7. Return new status

**Reset (`async def reset_portfolio(user_id, db)`):**
1. Delete all DryRunPositionDB for user
2. Reset DryRunPortfolioDB: cash=initial_capital, total_equity=initial_capital, unrealized_pnl=0, realized_pnl=0, trade_count=0, win_count=0. Keep is_active unchanged.
3. Broadcast dry_run_portfolio_update
4. Return new portfolio state

**Get status (`def get_status(user_id, db)`):**
Return dict with: is_active, positions (list), virtual_pnl (realized + unrealized), trade_count, win_rate, initial_capital, cash, total_equity.

**Get portfolio (`def get_portfolio(user_id, db)`):**
Return full portfolio state with current mark-to-market equity.

**Get decisions (`def get_decisions(user_id, db, from_date, to_date, action, symbol, limit, offset)`):**
Query DryRunDecisionDB with filters. Return paginated list.

**Get decision detail (`def get_decision(user_id, decision_id, db)`):**
Return single decision with full factor breakdown.

**WebSocket broadcasting:**
Use `get_stream_manager()._broadcast_to_user(user_id, message)` for:
- `dry_run_decision`: After each evaluation
- `dry_run_status`: After toggle
- `dry_run_portfolio_update`: After buy/sell/reset

**Critical implementation details:**
- Use `SessionLocal()` for DB operations inside the evaluation loop (not the FastAPI dependency injection `get_db()` which is request-scoped). Remember to close sessions properly.
- Use `Decimal(str(value))` when converting from API response floats.
- Fee rate default: Decimal("0.001") (0.1%), slippage default: Decimal("0.0005") (0.05%) — matching backtest defaults.
- Position fraction default: Decimal("0.10") (10% of virtual equity per trade).
- UUID generation for decision IDs: `f"drd_{uuid.uuid4().hex[:12]}"`, portfolio IDs: `f"drp_{uuid.uuid4().hex[:12]}"`, position IDs: `f"drpos_{uuid.uuid4().hex[:12]}"`.

6 endpoints:

1. `GET /{user_id}/status` — Returns dry-run status:
   - Call `get_dry_run_service().get_status(user_id, db)`
   - Returns: `{is_active, positions: [...], realized_pnl, unrealized_pnl, trade_count, win_rate, initial_capital, cash, total_equity}`
   - Error handling: try/except with logger.exception and generic 500

2. `POST /{user_id}/toggle` — Toggle dry-run on/off:
   - Call `await get_dry_run_service().toggle_dry_run(user_id, db)`
   - Returns: `{is_active, message}` ("Dry-Run aktiviert" / "Dry-Run deaktiviert")
   - Error handling: try/except

3. `GET /{user_id}/decisions` — Filterable decision log:
   - Query params: `from_date: Optional[str]`, `to_date: Optional[str]`, `action: Optional[str]`, `symbol: Optional[str]`, `limit: int = 50`, `offset: int = 0`
   - Validate action is one of BUY/SELL/HOLD/NO_SIGNAL if provided
   - Call `get_dry_run_service().get_decisions(user_id, db, ...)`
   - Returns: `{decisions: [...], total: int, limit: int, offset: int}`
   - Each decision: `{id, symbol, action, reason, alpha_score, trade_signal, quality, current_price, trailing_stop_level, regime_label, regime_hurst, virtual_qty, virtual_price, virtual_fee, evaluated_at, factors: [...]}`

4. `GET /{user_id}/decisions/{decision_id}` — Decision detail:
   - Call `get_dry_run_service().get_decision(user_id, decision_id, db)`
   - 404 if not found
   - Returns full decision with factors_json expanded

5. `POST /{user_id}/reset` — Reset virtual portfolio:
   - Call `await get_dry_run_service().reset_portfolio(user_id, db)`
   - Returns: `{message: "Portfolio zurueckgesetzt", portfolio: {...}}`
   - Error handling: try/except

6. `GET /{user_id}/portfolio` — Current virtual portfolio:
   - Call `get_dry_run_service().get_portfolio(user_id, db)`
   - Returns: `{initial_capital, cash, total_equity, unrealized_pnl, realized_pnl, trade_count, win_count, win_rate, is_active, positions: [...], activated_at}`
   - Error handling: try/except
