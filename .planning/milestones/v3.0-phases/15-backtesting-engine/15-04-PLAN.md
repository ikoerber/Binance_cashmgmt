**1. Add sweep methods to `backend/app/services/backtest_data_service.py`:**

a. `_generate_sweep_combinations(self, sweep_config: dict) -> List[dict]`:
   - Takes sweep_config with fields like:
     ```python
     {
       "zscore_window": {"min": 30, "max": 90, "step": 15},    # -> [30, 45, 60, 75, 90]
       "entry_threshold": {"min": 2.0, "max": 4.0, "step": 0.5},  # -> [2.0, 2.5, 3.0, 3.5, 4.0]
       "atr_multiplier": {"min": 1.5, "max": 3.0, "step": 0.5},
       "weight_zscore": {"min": 30, "max": 50, "step": 10},
       // ... etc.
     }
     ```
   - Generates all parameter combinations via `itertools.product`.
   - Returns list of override dicts for BacktestConfig.
   - Validates: combination count must be <= 500 (hard cap). Returns ValueError if exceeded.

b. `async def run_sweep(self, user_id: str, symbol: str, months: int, initial_capital: Decimal, base_config: dict, sweep_config: dict, db: Session, ws_manager=None) -> dict`:
   - Generate combinations.
   - Create sweep_id: `f"sweep_{uuid.uuid4().hex[:12]}"`.
   - Fetch candle data ONCE (shared across all combinations).
   - For each combination:
     - Build BacktestConfig with combination overrides.
     - Run `run_alpha_backtest()` in `asyncio.to_thread()`.
     - Check cancel_event between combinations.
     - Broadcast sweep progress via WebSocket: `{"type": "backtest_progress", "run_id": sweep_id, "phase": "sweep", "combination_current": i+1, "combination_total": total, "progress_pct": ..., "elapsed_seconds": ...}`.
     - Persist each result with `sweep_id` reference.
   - Return summary: `{"sweep_id": ..., "combination_count": ..., "results": [list of {config_overrides + key metrics}]}`.
   - On cancellation: return partial results (all completed combinations).

c. **WebSocket progress broadcasting:**
   Add progress broadcasting to `run_backtest()` (the single-run method from Plan 02):
   - Before data fetch: broadcast `{"type": "backtest_progress", "run_id": ..., "phase": "fetching_data", "progress_pct": 0}`.
   - During simulation: pass a progress_callback to `run_alpha_backtest()` that broadcasts `{"type": "backtest_progress", "run_id": ..., "phase": "simulating", "progress_pct": ..., "candles_processed": ..., "candles_total": ..., "trades_found": ...}`.
   - Throttle progress callbacks to every 250ms (not every candle). Use `time.monotonic()` to track last broadcast time.
   - On completion: broadcast `{"type": "backtest_progress", "run_id": ..., "phase": "complete", "progress_pct": 100}`.
   - On cancellation: broadcast `{"type": "backtest_progress", "run_id": ..., "phase": "cancelled"}`.
   - The ws_manager is passed from the API route (it accesses the global websocket_manager).

d. `def generate_sweep_csv(self, db: Session, user_id: str, sweep_id: str) -> Optional[str]`:
   - Query all AlphaBacktestRunDB where sweep_id matches and user_id matches.
   - Use `csv.DictWriter` + `io.StringIO` to generate CSV.
   - Columns: all config overrides + key metrics (net_return_pct, sharpe_ratio, max_drawdown_pct, trade_count, win_rate, total_fees, total_slippage, benchmark_return_pct, excess_return_pct).
   - Return CSV string (or None if sweep not found).

**2. Add sweep + CSV endpoints to `backend/app/api/routes/backtest.py`:**

a. `POST /api/backtest/{user_id}/sweep`:
   - Body: `{"symbol": "BTCEUR", "months": 12, "initial_capital": "10000", "fee_rate": "0.001", "slippage_pct": "0.0005", "position_fraction": "0.10", "sweep": {"zscore_window": {"min": 30, "max": 90, "step": 15}, ...}}`
   - Validates: combination count computed upfront. If > 500: return 400 with `{"error": "Zu viele Kombinationen", "combination_count": N, "max_allowed": 500}`.
   - Calls `service.run_sweep()`.
   - Returns 200 with sweep summary.

b. `GET /api/backtest/{user_id}/sweep/{sweep_id}/csv`:
   - Returns CSV as `text/csv` with `Content-Disposition: attachment; filename="sweep_{sweep_id}.csv"`.
   - 404 if sweep not found.

c. `GET /api/backtest/{user_id}/sweep/{sweep_id}`:
   - Returns all runs belonging to this sweep (summary metrics only, no equity curves).

**Error handling:** All routes follow project pattern — `logger.exception()` + generic error responses.
