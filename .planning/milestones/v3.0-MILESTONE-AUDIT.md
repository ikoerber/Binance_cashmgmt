## Unsatisfied Requirements

### BOT-02: Alpha Score with factor breakdown (Phase 16)

**Issue:** `BotDashboard.jsx` reads wrong API response fields.
- Line 132: reads `composite_score` / `alpha_score` — actual field is `score`
- Line 156: reads `f.score` / `f.value` — actual field is `f.sub_score`

**Impact:** Alpha Score hero number always shows `--`. All 4 factor bars always show `0.00`.

**Fix:** 2 line changes in BotDashboard.jsx.

### BOT-05: Backtest results display (Phase 16)

**Issue:** `BotDashboard.jsx` line 213 expects `backtestRuns` to be an array, but API returns `{runs: [], count: N}` envelope.

**Impact:** Backtest summary card always shows "Kein Backtest" even when runs exist.

**Fix:** Unwrap envelope — access `backtestRuns?.runs` instead of bare `backtestRuns`.

### EXIT-01 / EXIT-02: Trailing stop display (Phase 14)

**Issue:** Backend endpoint `GET /api/alpha-score/{user_id}/trailing-stops` exists and computes correctly. No frontend consumer — `client.js` has no `getTrailingStops` function, no component displays trailing stop levels or freeze state.

**Impact:** Users cannot see ATR-adaptive trailing stop levels or freeze/resume state.

**Fix:** Add `getTrailingStops` to client.js, display in BotDashboard.
